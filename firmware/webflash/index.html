RAPT Pill · custom firmware installer

First install over the USB-UART cable, straight from Chrome. Every update after that is the pill's own /firmware page — no cable, no CLI.

1 · Wire it up

adapter RXD → pill E_TXD adapter TXD → pill E_RXD adapter GND → pill GND adapter RTS → pill EN strap (GPIO0) → GND clip pill powered from USB-C
Why the clip, and what the pins do

The header reads GND · E_TXD · E_RXD · strap · EN · 3V3. The strap pin is GPIO0: low at reset puts the ROM bootloader in charge, which is the only way to write flash. This adapter has no DTR, so the clip replaces it — clip on for flashing, clip off to run the app. VCC on the adapter is a 3.3 V output; leave it unplugged, the pill runs on its own USB-C power.

Send wires are crossed: the adapter's TXD goes to the pill's TXD-side pin labelled E_RXD, because that label names the pill's own direction.

2 · Connect

Clip on, pill powered, then pick the serial port Chrome offers.

3 · Flash

The app goes to 0x190000 (ota_1) and the boot sequence is written to 0xd000/0xd800. ota_0 keeps whatever is in it, so stock stays one button away.

4 · Run it

  1. Take the clip off the strap pin.
  2. Press Release reset — the RTS line pulses EN and the pill boots the new app.
  3. Unprovisioned pills raise RAPT-Pill-<mac tail>, password kegland1; open http://172.217.28.1/ and pick your Wi-Fi. A pill that already knows a network just joins it — check your router for 192.168.1.x.
  4. From then on, updates are POST /firmware from the pill's own pages.
